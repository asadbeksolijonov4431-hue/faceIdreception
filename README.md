python -m venv venv
venv\Scripts\activate (Windows PowerShell: .\venv\Scripts\Activate.ps1)


2) Kerakli paketlarni o'rnatish:
python -m pip install -r requirements.txt


3) Serverni ishga tushurish:
python app.py


4) Brauzerda ochish:
http://127.0.0.1:5000
